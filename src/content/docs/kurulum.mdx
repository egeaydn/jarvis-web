## İndirilebilir sürüm

İndirme merkezinde sunulan Windows x64 beta EXE’sini indir. Dosya boyutunu ve SHA-256 bilgisini kontrol et. Bu tek dosyalık uygulama için Python kurman gerekmez.

EXE’yi çift tıklayarak aç. İlk açılışta dosyaların geçici klasöre çıkarılması birkaç saniye sürebilir. **Ayarlar ve AI bağlantısı** bölümünden Groq’u seç, kendi API anahtarını gir ve kaydet. Anahtarın yoksa arayüz açık kalır; bağlantını daha sonra tamamlayabilirsin.

Beta henüz kod imzalı değildir; Windows yayıncı doğrulaması gösteremeyebilir. Temiz Windows kurulumu ve farklı cihaz testleri sürmektedir.

## Model bağlantısını yapılandır

.env.example dosyasını .env olarak kopyala. Seçtiğin sağlayıcının anahtarını kendi bilgisayarında ekle; kaynak kod deposuna koyma.

Masaüstü arayüzü model bağlantısını arka planda hazırlar. Yapılandırma eksikse Ayarlar ve AI bağlantısı bölümünden tamamla. Varsayılan sağlayıcı Groq’tur.

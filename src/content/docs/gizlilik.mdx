## Model bağlantısı

Sohbet istekleri ve araç sonuçları seçili sağlayıcıya gönderilebilir. Sonuçlarda dosya adları, yollar veya içerik bulunabilir. Jarvis'in bütün işlevleri çevrimdışı çalışmaz.

## Ses ve ekran

Konuşma tanıma Google üzerinden, ekran analizi Gemini üzerinden çalışır. STT tabanlı uyandırmada da ses dış servise gönderilebilir.

Web sitesindeki demo ses kaydetmez, ekranını okumaz ve bilgisayarında komut yürütmez.

</section>

<section className="doc-section" id="yerel">

## Yerel kayıtlar

Paketlenmiş uygulama sohbet, araç, not ve hatırlatıcı kayıtlarını Windows kullanıcı klasöründeki **%LOCALAPPDATA%\\EgeAssistant\\Jarvis** dizininde saklayabilir. Kaynak koddan çalıştırmada data dizini kullanılır.

Pano geçmişi ve arka plan mikrofonu yeni kurulumda kapalıdır; Ayarlar bölümünden açılabilir. API anahtarları Windows kullanıcı hesabına bağlı şifrelemeyle kaydedilir. İndirilen EXE kişisel API anahtarlarını veya geliştiricinin sohbet geçmişini içermez. “Sohbeti temizle” ekranı temizler; diskteki bütün kayıtları sildiği anlamına gelmez.

</section>
